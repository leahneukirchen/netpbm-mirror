NAME

pbmtobrush - convert a PBM image to a doodle brush file

SYNOPSIS

pbmtobrush [pbmfile]

DESCRIPTION

This program is part of Netpbm.

pbmtobrush reads a PBM image as input and produces a Xerox doodle brush file as output.

OPTIONS

There are no command line options defined specifically for pbmtobrush, but it recognizes the options common to all programs based on libnetpbm (See Common Options.)
