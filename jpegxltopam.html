NAME

jpegxltopam - convert JPEG XL image to PAM

SYNOPSIS

jpegxltopam filename [-verbose]

Minimum unique abbreviation of option is acceptable. You may use double hyphens instead of single hyphen to denote options. You may use white space in place of the equals sign to separate an option name from its value.

DESCRIPTION

This program is part of Netpbm.

jpegxltopam converts the named JPEG XL image (JXL) file to a PAM image on Standard Output.

If the JPEG XL input is true JPEG XL, the PAM output is not true PAM, but instead a variant with samples in the sRGB color space. True PAM uses the ITU-R Recommendation BT.709 color space. The two color spaces are similar enough that people will not normally notice the difference. Furthermore, there are probably many ostensible JPEG XL images that are actually a variant that decodes as BT.709 pixels, and if you start with one of those JPEG XL images, your output will in fact be true PAM. For example, if you create a JPEG XL image with pamtojpegxl, you will get such an approximate JPEG XL, and if you convert it back to PAM with jpegxltopam, you get valid PAM. So this is not necessarily a problem. If it is, you can use pnmgamma to create true PAM from the sRGB variant produced by this program.

This program generates a 4-plane PAM of tuple type RGB_ALPHA, i.e. a color image with transparency. You can convert that to PPM if you like, discarding any transparency information, with pamtopnm.

EXAMPLES

  jpegxltopam testimg.jxl >testimg.pam

OPTIONS

In addition to the options common to all programs based on libnetpbm (most notably -quiet, see Common Options), jpegxltopam recognizes the following command line options:

-verbose
This causes jpegxltopam to issue messages about the input and the processing of it.
